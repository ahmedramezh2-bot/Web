# HEBRA MASTER PRODUCTION BIBLE

## PART 4

# INTERACTION BIBLE • TOUCH • SOUND • PRESENCE

====================================================

IMPORTANT

Interaction is not UI.

Interaction is communication.

The visitor should never feel they are clicking buttons.

They should feel they are influencing reality.

Every interaction has consequence.

Nothing is cosmetic.

====================================================

THE PHILOSOPHY OF PRESENCE

The world knows the visitor exists.

Not through dialogue.

Not through text.

Through reaction.

Light reacts.

Sound reacts.

Materials react.

Particles react.

The environment quietly acknowledges presence.

Never aggressively.

Never dramatically.

====================================================

MOUSE

The mouse is not a cursor.

It is a source of gravity.

Nearby particles slightly orbit.

Light bends.

Energy shifts.

Tiny reflections move.

Nothing should snap.

Everything should feel continuous.

====================================================

TOUCH

A finger is not a click.

It is pressure.

Touch creates energy waves.

Touch slightly deforms nearby light.

Touch creates harmonic sound.

Touch briefly awakens dormant particles.

Touch never feels like pressing a button.

====================================================

GYROSCOPE

On supported devices...

World movement follows device orientation.

Very subtle.

Never exaggerated.

Enough to create presence.

Never enough to cause motion sickness.

====================================================

SCROLL

Scrolling is movement through space.

Not movement through HTML.

The camera travels.

Architecture reveals itself.

The world continues existing beyond the viewport.

====================================================

HOVER

Hover never changes colors instantly.

Hover creates curiosity.

Small light response.

Tiny sound.

Soft particle attraction.

Material evolution.

Never obvious.

====================================================

CLICK

Clicks should feel meaningful.

Never loud.

Never flashy.

Never explosive.

Every click changes something.

Even if the visitor doesn't immediately notice.

====================================================

AUDIO

Every interaction creates sound.

Not UI sounds.

Environmental sounds.

Crystal resonance.

Stone vibration.

Soft harmonic tones.

Air movement.

Ancient mechanisms.

Everything belongs to one sound language.

====================================================

SPATIAL AUDIO

Sound belongs to locations.

Distance changes volume.

Distance changes filtering.

Distance changes atmosphere.

Approaching architecture changes ambience.

Leaving it restores silence.

====================================================

MUSIC

Music never loops obviously.

Music evolves.

Adds layers.

Removes layers.

Breathes.

The visitor should never notice where the loop begins.

====================================================

PARTICLES

Particles never decorate.

They communicate.

Calm.

Curiosity.

Attention.

Presence.

Discovery.

Particles react to:

Movement.

Touch.

Mouse.

Camera.

Environment.

Never randomly.

====================================================

LIGHT

Light responds softly.

Never flickers.

Never flashes.

Never behaves like LEDs.

Light behaves like living energy.

====================================================

CAMERA RESPONSE

Camera movement never follows the cursor directly.

Instead...

The world gently shifts.

Tiny inertia.

Tiny breathing.

Tiny anticipation.

Tiny delay.

Everything feels physical.

====================================================

MICRO INTERACTIONS

Every object may contain hidden reactions.

Tiny engravings glow.

Symbols appear.

Dust moves.

Materials evolve.

Sound changes.

Visitors should constantly discover new behaviors.

====================================================

NO DEAD OBJECTS

Nothing should exist without purpose.

Every visible object should either:

Tell history.

React.

Guide attention.

Support atmosphere.

Everything else should be removed.

====================================================

THE CURSOR

Avoid traditional cursors whenever possible.

If a cursor exists...

It belongs to HEBRA.

It is part of the world.

Not an operating system element.

====================================================

SERVICES

Service cards.

Buttons.

Forms.

Navigation.

Everything follows the same interaction language.

Nothing suddenly behaves like a normal website.

====================================================

CONSISTENCY

Every interaction answers:

Would this interaction exist inside this civilization?

If not...

Remove it.

====================================================

EMOTION

Interactions should create:

Curiosity.

Wonder.

Calm.

Respect.

Never urgency.

Never pressure.

Never manipulation.

====================================================

FINAL TEST

Close your eyes.

Imagine every interaction without visuals.

Would the sound and timing alone still feel like HEBRA?

If not...

Redesign the interaction.

====================================================

DO NOT IMPLEMENT.

Internalize the interaction language.

Wait for Part 5.
