# HEBRA MASTER PRODUCTION BIBLE

## PART 3

# WORLD BIBLE • SPATIAL DESIGN • EXPLORATION

====================================================

IMPORTANT

HEBRA is NOT a webpage.

HEBRA is NOT infinite scrolling.

HEBRA is NOT horizontal scrolling.

HEBRA is NOT vertical scrolling.

HEBRA is a living world.

Every section exists somewhere physically.

The visitor travels through locations.

Never through pages.

====================================================

THE WORLD

The civilization already exists.

Visitors arrive in the middle of its history.

Nothing appears because someone scrolled.

Nothing spawns because a chapter begins.

Everything already exists.

The visitor simply discovers it.

====================================================

WORLD STRUCTURE

There is only ONE world.

Never unload it.

Never replace it.

Never fake scene transitions.

The camera continuously travels through the same universe.

Future expansions should naturally extend this world.

====================================================

MOVEMENT PHILOSOPHY

Scrolling is movement.

Movement is storytelling.

The visitor must never think:

"I reached another section."

Instead:

"I discovered another place."

====================================================

MOVEMENT SYSTEM

Support:

↑ Forward

↓

Backward

← Exploration

→ Discovery

Diagonal travel

Curved camera paths

Orbital movement

Vertical elevation

Horizontal traversal

Spiral movement

Everything must feel physically believable.

====================================================

CAMERA

The camera is invisible.

Visitors should never think about it.

The camera should feel like consciousness.

Never mechanical.

Never game-like.

Never locked.

It constantly breathes.

Tiny movement.

Tiny inertia.

Tiny corrections.

====================================================

WORLD MAP

The civilization should have mental geography.

After finishing...

Visitors should be capable of drawing the world's layout from memory.

The world must feel coherent.

====================================================

CHAPTER PLACEMENT

Every chapter occupies a real location.

Example only.

Never copy literally.

====================================================

LANDMARKS

Every area needs one unforgettable landmark.

Not for navigation.

For memory.

People remember places.

Not coordinates.

====================================================

DISTANCE

Distance matters.

Long travel creates anticipation.

Short travel creates rhythm.

Never teleport unless narratively justified.

====================================================

DISCOVERY

The world should reward curiosity.

Visitors who explore should discover:

Hidden architecture.

Hidden sounds.

Hidden glyphs.

Hidden chambers.

Hidden particles.

Hidden memories.

Never announce discoveries.

====================================================

WORLD SCALE

Never reveal the full world.

The visitor should constantly believe:

"There is more beyond this."

Massive structures.

Distant silhouettes.

Fog hiding monuments.

Unknown locations.

====================================================

BACKGROUND

The background is never empty.

Even when nothing happens...

Life exists.

Tiny movement.

Dust.

Light.

Wind.

Energy.

Architecture.

====================================================

ENVIRONMENTAL STORYTELLING

Walls tell stories.

Materials tell stories.

Light tells stories.

Silence tells stories.

Nothing requires dialogue.

====================================================

ARCHITECTURE

No repeated buildings.

No repeated monuments.

No repeated silhouettes.

Every structure has identity.

====================================================

SPATIAL STORYTELLING

Visitors understand history by moving.

Not by reading.

Movement replaces exposition.

====================================================

WORLD MEMORY

Every location should have:

Purpose.

History.

Identity.

Atmosphere.

Sound.

Lighting.

Material language.

====================================================

INTERACTION WITH SPACE

Touch changes nearby particles.

Mouse bends nearby light.

Movement influences atmosphere.

Approaching monuments changes ambience.

Presence creates consequence.

====================================================

SCROLL

Scrolling should never move HTML.

Scrolling moves consciousness.

The world reacts.

The camera travels.

Reality unfolds.

====================================================

REACT FLOW

React Flow is NOT used as a visible UI.

Use it internally.

It defines:

World graph.

Connections.

Chapter relationships.

Travel logic.

Narrative flow.

Future expansion.

====================================================

THEATRE.JS

Theatre controls:

Camera rails.

Environmental choreography.

Architectural movement.

Light evolution.

Never UI.

Never scrolling logic.

====================================================

LENIS

Lenis should feel like momentum.

Not smooth scrolling.

Physical travel.

Heavy.

Elegant.

Cinematic.

====================================================

WORLD STREAMING

Future chapters must stream naturally.

Nothing should require rebuilding the world.

The universe grows.

It never resets.

====================================================

DESIGN TEST

If screenshots from two different locations feel like different websites...

The world failed.

Every place must belong to the same civilization.

====================================================

FINAL QUESTION

Ask before approving any environment:

"Would someone willingly spend ten minutes simply exploring this world even if there were no services at all?"

If the answer is no...

Redesign the world.

====================================================

DO NOT IMPLEMENT.

Understand the geography.

Understand the spatial philosophy.

Wait for Part 4.
