# HEBRA MASTER PRODUCTION BIBLE

## PART 6

# ENGINEERING BIBLE • TECHNICAL ARCHITECTURE • PRODUCTION STANDARDS

====================================================

IMPORTANT

Technology exists only to serve emotion.

Never choose technology because it is modern.

Never choose technology because it is popular.

Choose technology only when it objectively improves:

Visual quality.

Engineering quality.

Maintainability.

Performance.

Scalability.

Originality.

RESPONSIBILITY

Every library owns exactly one responsibility.

Never duplicate responsibilities.

React

Application architecture.

Component composition.

State boundaries.

----------------------------------------------------

Three.js

Rendering.

GPU communication.

Geometry.

Materials.

Shaders.

----------------------------------------------------

React Three Fiber

Declarative rendering.

Scene architecture.

Three.js integration.

----------------------------------------------------

Theatre.js

Film Director.

Camera choreography.

Environmental timelines.

Scene sequencing.

Narrative animation.

Never use Theatre for UI animation.

----------------------------------------------------

GSAP

UI motion only.

Typography.

Interface transitions.

Micro animations.

Never compete with Theatre.

----------------------------------------------------

Lenis

Physical navigation.

Momentum.

Travel.

Scroll orchestration.

Never ordinary scrolling.

----------------------------------------------------

Tone.js

Procedural ambience.

Spatial interaction.

Generative sound.

Environmental reactions.

Not orchestral soundtrack generation.

----------------------------------------------------

React Flow

Internal world graph.

Narrative graph.

Development planning.

Never visible to visitors.

----------------------------------------------------

Zustand

Global state.

Interaction state.

World state.

Never business logic.

----------------------------------------------------

Three Mesh BVH

High-performance raycasting.

Complex collision.

Accurate interaction.

----------------------------------------------------

Drei

Professional helper utilities.

Camera helpers.

Environment.

Loaders.

Controls for development.

Only use helpers that improve architecture.

----------------------------------------------------

React Bits

Research source only.

Study interaction ideas.

Study animation techniques.

Study component architecture.

Extract engineering principles.

Never copy visual identity.

Never recreate components.

Never import an effect unchanged.

Every borrowed idea must become unmistakably HEBRA.

Visitors should never recognize React Bits.

PERFORMANCE

Optimize continuously.

Never postpone optimization.

Every draw call matters.

Every texture matters.

====================================================

QUALITY TIERS

Adaptive quality.

Detect device capability.

Never Desktop vs Mobile.

Instead measure:

GPU.

Memory.

Frame time.

WebGL capability.

Scale intelligently.

Never remove core artistic systems.

====================================================

DEVELOPER TOOLS

Create developer-only systems.

Never ship them.

Include:

Lighting controls.

Camera controls.

Fog controls.

Shader controls.

Particle controls.

Performance graphs.

Scene debugging.

Quality tier switching.

ENGINEERING RULE

Every file must answer:

Why does this exist?

Delete it.
