Part 7

IMPORTANT

Do NOT implement yet.

Do NOT write animation code.

Do NOT build timelines.

Do NOT create keyframes.

This document defines the philosophy of movement inside the HEBRA universe.

Movement is not decoration.

Movement is life.

Everything moves because it is alive.

Never because animation looks impressive.

====================================================

THE PHILOSOPHY OF MOTION

Nothing inside HEBRA should ever feel static.

Even complete silence contains movement.

Tiny breathing.

Tiny vibration.

Tiny shifts in light.

Tiny particle motion.

The universe should always feel alive.

====================================================

THE LANGUAGE OF MOTION

Every animation must communicate one emotion.

Wonder.

Curiosity.

Respect.

Silence.

Discovery.

Hope.

Legacy.

Never animate without emotional purpose.

====================================================

NO GENERIC ANIMATIONS

Reject immediately:

Bounce.

Elastic UI effects.

Overused easing.

Game-like floating.

Random rotations.

Looping showcase animations.

Everything should feel handcrafted.

====================================================

NATURAL PHYSICS

Objects have weight.

Large objects accelerate slowly.

Heavy objects stop gradually.

Light reacts before matter.

Particles react before structures.

Momentum always exists.

====================================================

TIMING

Animation timing is storytelling.

Some events happen in milliseconds.

Others require several seconds.

Never rush discovery.

Let anticipation build naturally.

The visitor should sometimes wait.

Waiting creates emotional value.

====================================================

THEATRE.JS

Theatre.js should become the cinematic director.

Every important sequence should be directed through Theatre timelines.

Camera.

Lighting.

Particles.

Environment.

Music layers.

Transitions.

Scene evolution.

Theatre should orchestrate the experience.

====================================================

GSAP

GSAP controls interface precision.

Micro interactions.

State transitions.

Typography.

Buttons.

Panels.

UI transformations.

Never use GSAP for cinematic sequences that belong to Theatre.

Separate responsibilities clearly.

====================================================

REACT THREE FIBER

React Three Fiber is responsible for the living world.

Never create isolated 3D scenes.

Everything belongs to one continuous universe.

Objects continue existing outside the camera.

Nothing appears because scrolling reached it.

The universe always exists.

====================================================

SCENE TRANSITIONS

Never fade between scenes.

Reality transforms.

Geometry becomes architecture.

Light becomes matter.

Particles become symbols.

Symbols become worlds.

The visitor should never notice scene boundaries.

====================================================

LOOPS

Visible loops destroy immersion.

Every idle animation should contain variation.

Different duration.

Different amplitude.

Different phase.

Nothing repeats perfectly.

====================================================

OBJECT PERSONALITY

Every important object has its own movement language.

Some breathe.

Some pulse.

Some rotate almost imperceptibly.

Some remain almost motionless.

Movement reflects personality.

====================================================

CAMERA SYNCHRONIZATION

Environment.

Particles.

Light.

Music.

Animation.

Camera.

Everything should evolve together.

Nothing moves independently without purpose.

====================================================

PERFORMANCE

Animation quality must never sacrifice performance.

Maintain fluidity.

Prefer stable frame pacing.

Optimize intelligently.

Reduce unnecessary calculations.

Create complexity through design, not brute force.

====================================================

THE FINAL TEST

Before accepting any animation ask:

Does it strengthen immersion?

Does it tell part of the story?

Does it belong only to HEBRA?

Would removing it make the experience weaker?

If not...

Remove it.

====================================================

FINAL OBJECTIVE

The visitor should never admire the animation itself.

They should forget animation exists.

They should simply believe the universe is alive.

Wait for the next Creative Bible.
