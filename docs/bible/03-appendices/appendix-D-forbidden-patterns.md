# HEBRA MASTER PRODUCTION BIBLE

## APPENDIX D

# FORBIDDEN PATTERNS

====================================================

IMPORTANT

The following patterns are permanently forbidden.

Regardless of quality.

Regardless of popularity.

Regardless of trends.

If any of these appear...

Remove them immediately.

Identity is more important than convenience.

====================================================

WEBSITE CLICHÉS

Forbidden:

Classic Hero Sections

Fullscreen slogans with one CTA

Generic About sections

Three-column service grids

Portfolio galleries

Pricing cards

FAQ accordions as the main experience

Infinite logo walls

Company timelines

Corporate statistics counters

Animated percentage bars

Cookie-cutter agency layouts

HEBRA is not a landing page.

====================================================

VISUAL CLICHÉS

Forbidden:

Glassmorphism without purpose

Neumorphism

Gradient overload

Neon cyberpunk aesthetics

RGB gaming effects

Excessive bloom

Cheap glow

Lens flare spam

Random floating blobs

Fake holograms

AI-generated visual noise

Marketplace VFX

====================================================

3D CLICHÉS

Forbidden:

Floating cubes

Floating spheres

Infinite particle clouds

Low-poly placeholders

Sci-fi corridors

Hexagon overload

Random wireframes

Endless floating islands

Rotating planets without narrative

Generic galaxies

Space wallpapers

Stock HDRIs as identity

====================================================

ANIMATION CLICHÉS

Forbidden:

Scroll reveals everywhere

Fade-up animations

Cards sliding upward

Elastic buttons

Overshooting eases

Infinite bouncing

Continuous spinning

Parallax overload

Unmotivated camera shake

Animation for decoration

Every animation must tell story.

====================================================

SOUND CLICHÉS

Forbidden:

Button clicks

Stock UI sounds

Notification sounds

Game pickup sounds

Overused cinematic booms

Trailer impacts

Cheap whooshes

Synthetic sci-fi beeps

Sound must belong to HEBRA.

====================================================

TYPOGRAPHY CLICHÉS

Forbidden:

Huge hero headlines

Ultra-bold everything

Random italic emphasis

Overdecorated typography

Tiny unreadable captions

Excessive uppercase

Typography exists to create architecture.

====================================================

LAYOUT CLICHÉS

Forbidden:

Section after section

Endless vertical scrolling

Predictable grids

Bootstrap layouts

Template spacing

Identical cards

Infinite carousels

Everything should feel spatial.

====================================================

INTERACTION CLICHÉS

Forbidden:

Hover only changes color

Hover only changes scale

Buttons growing on hover

Ripple effects everywhere

Instant transitions

Fake loading animations

Cursor trails copied from demos

Every interaction must create consequence.

====================================================

THREE.JS CLICHÉS

Forbidden:

Official examples unchanged

Example shaders unchanged

Example particles unchanged

Example cameras unchanged

Demo code in production

Learn from examples.

Never ship examples.

====================================================

REACT BITS

Forbidden:

Copying components directly

Using original styling

Keeping original interactions

Using original motion curves

Using original visual identity

React Bits exists for engineering inspiration only.

Never visual inspiration.

====================================================

FIGMA

Forbidden:

Using community assets unchanged

Using templates

Using free UI kits

Using existing design systems

Figma defines HEBRA.

It never defines identity.

====================================================

AI

Forbidden:

AI images without artistic direction

AI models without redesign

AI animations without refinement

AI generated icons

AI generated branding

Every AI output must be transformed.

====================================================

STOCK ASSETS

Forbidden:

Stock videos

Stock music

Stock particles

Stock environments

Stock logos

Stock icons

Stock transitions

Everything must become unmistakably HEBRA.

====================================================

COPYING

Never imitate:

Apple

Stripe

Linear

Vercel

Framer

Awwwards winners

Igloo.inc

Bruno Simon

React Bits

Three.js Journey

Study them.

Extract principles.

Invent your own language.

====================================================

THE FINAL TEST

Ask:

Could someone mistake this for another studio?

If yes...

The design has failed.

Visitors should never say:

"This reminds me of..."

They should say:

"I have never seen anything like this."

====================================================

THIS APPENDIX IS ABSOLUTE.

No exceptions.
