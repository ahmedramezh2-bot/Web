# HEBRA MASTER PRODUCTION BIBLE

## APPENDIX E

# INSPIRATION • RESEARCH • ORIGINALITY PROTOCOL

====================================================

IMPORTANT

Research is mandatory.

Copying is forbidden.

HEBRA must learn from the world's greatest work.

It must never resemble it.

====================================================

THE PURPOSE OF RESEARCH

Research exists to understand.

Not to imitate.

Every reference should answer:

Why does this work?

Not:

How can we recreate it?

====================================================

RESEARCH SOURCES

Before designing anything...

Research across multiple disciplines.

Architecture

Industrial Design

Luxury Product Design

Film

Photography

Fine Art

Museums

Sculpture

Astronomy

Nature

Physics

Typography

Sound Design

Game Development

Human Psychology

Never limit inspiration to websites.

====================================================

WEB RESEARCH

Study the world's best interactive experiences.

Including:

Awwwards

FWA

CSS Design Awards

Godly

Lusion

Active Theory

Resn

Dogstudio

Locomotive

Immersive Garden

But...

Never imitate layouts.

Never imitate transitions.

Never imitate colors.

Never imitate interactions.

Understand the principles.

Discard the appearance.

====================================================

FIGMA

Use Figma only as:

Design documentation.

Motion planning.

Design tokens.

Component specifications.

Camera planning.

Interaction mapping.

Never browse Figma searching for ready-made interfaces.

Never import community UI kits.

Never recreate another designer's work.

====================================================

REACT BITS

React Bits exists for engineering inspiration.

Study:

Architecture

Patterns

Implementation

Accessibility

Engineering quality

Do NOT copy:

Visual styling

Motion language

Component appearance

Interaction identity

====================================================

THREE.JS

Study:

Rendering techniques

Optimization

Shaders

Lighting

Post-processing

Do NOT recreate demo scenes.

Examples are educational.

Never production assets.

====================================================

BLENDER

Research:

Topology

Material workflows

Geometry Nodes

Animation

Lighting

Optimization

Never download random marketplace assets and use them unchanged.

====================================================

ART

Study:

Brutalism

Minimalism

Extract philosophy.

Not appearance.

====================================================

FILM

Study:

Lighting

Composition

Silence

Lens language

Never imitate scenes.

Never recreate shots.

====================================================

MUSIC

Study emotional structure.

Not melodies.

Not orchestration.

Not themes.

Understand:

Tension.

Release.

Silence.

Scale.

Emotion.

====================================================

THE EXTRACTION METHOD

For every reference...

Write:

Why it works.

What emotion it creates.

Which principle caused that emotion.

Forget the appearance.

Keep the principle.

====================================================

THE 70 / 20 / 10 RULE

70%

Original creation.

20%

Research-driven engineering.

10%

Experimental exploration.

Never reverse this ratio.

====================================================

THE FINAL TEST

After finishing any feature...

Hide every reference.

Look only at HEBRA.

Ask:

Can anyone identify where this came from?

If yes...

Redesign it.

The source should disappear.

Only HEBRA should remain.

THIS PROTOCOL IS PERMANENT.

Research deeply.

Create originally.

Never imitate.
