# H E B R A

> A dimension where ideas become matter.

This repository contains the HEBRA experience — digital cinema,
not a website. It is being built in phases against a fixed
Creative Bible.

**Current phase: 1 — Foundation.** The universe exists (stage,
systems, direction pipeline, sound engine, quality tiers) and is
deliberately dark: chapters arrive in later phases.

## Run

```sh
npm install
npm run dev        # development, with the director's console
npm run build      # strict typecheck + production build
npm run preview    # serve the production build locally
```

Open with `?edit` on any build to mount the Theatre.js console.

## Read first

- `ARCHITECTURE.md` — the responsibility map and the hard rules.
- `src/story/chapters.ts` — the emotional curve of the journey.
- `src/scenes/chapters/README.md` — the chapter contract.
